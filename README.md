# 80-20 학습 포탈 (아이 학습 + 부모 리포트)

교육과정 기반 적응학습 웹앱 모음입니다. 서버 없이 정적 파일만으로 동작하며 외부 의존성이 없습니다.

## 구성

| 파일 | 역할 |
|---|---|
| `index.html` | 통합 포탈 — 아이 학습 진입 + 부모 리포트 + 설정 |
| `social.html` | 중1 사회 Ⅰ·Ⅱ (개념 26 / 문항 156) |
| `english.html` | 초4 영어 문법·단어·회화 (개념 30 / 문항 180) |

## 사용

1. `index.html` 을 열면 학습자 카드가 보입니다.
2. [오늘 학습] → 해당 아이의 `학습 시작` → 15문항 세션.
3. [부모 리포트] → 아이별 이번 주 세션·정답률·취약 개념·다음에 배울 개념·집에서 해줄 것.
4. [설정] → 학습자 이름 변경, 이름·난이도 설정을 다른 기기로 복사.

학습자 이름은 기본값이 코스 라벨('중1 사회', '초4 영어')입니다. 설정 탭에서 바꾸면 이 브라우저에만 저장됩니다.

## 원리

이미 아는 맥락 80~90%에 새로운 맥락 10~20%를 섞어, 정답률 85% 부근을 계속 유지합니다.

1. 진단 12문항으로 개념별 현재 위치를 먼저 잡는다(0에서 시작하지 않음)
2. 매 문항마다 예상 정답률을 계산해 목표에 가장 가까운 난이도를 고른다
3. 세션 15문항 = 익숙 + 도전(난이도 단계별로 12+3 / 11+4 / 9+6)
4. 오답 즉시 재교수 카드, 세션 끝에 '자기 전 5분' 복습 카드

배경 근거: 이해 가능한 입력(i+1, Krashen 1985), 최적 오류율 85% 규칙(Wilson et al., Nature Communications 2019), 수면 중 기억 공고화.

## 난이도

| 단계 | 목표 정답률 | 세션 구성 |
|---|---|---|
| 안정 (기본) | 85% | 익숙 12 + 새 개념 3 |
| 도전 | 75% | 익숙 11 + 새 개념 4 |
| 가속 | 65% | 익숙 9 + 새 개념 6 |

## 기록

학습 기록은 접속한 브라우저의 localStorage에 저장됩니다. 기기 간 동기화는 미구현이며, 이름·난이도 설정만 포탈 [설정]의 복사/붙여넣기로 옮길 수 있습니다.

## 빌드

이 저장소의 HTML 3장은 모두 생성물입니다. 콘텐츠·엔진 수정은 원본 생성기에서 하고 아래 세 줄로 다시 만듭니다.

```
python _build_app.py --out <이 저장소>/social.html
python _build_eng.py --out <이 저장소>/english.html
python _hub_build.py --out <이 저장소>/index.html
```

원본 생성기는 개인 작업 폴더에 있으며 이 저장소에는 산출물만 둡니다. AI에게 새 문항을 받아 붙여넣는 확장 루프는 각 코스 페이지의 [리포트] 탭에 있습니다.
