# 80-20 적응학습 (중1 사회 Ⅰ·Ⅱ)

교육과정 기반 적응학습 웹앱. `index.html` 단일 파일로 동작하며 외부 의존성이 없습니다.

- 대상: 천재교과서 중학교 사회 ①(2022 개정) — Ⅰ. 세계화 시대, 지리의 힘 / Ⅱ. 아시아
- 콘텐츠: 개념 26개 / 문항 156개 (개념당 6문항, 난이도 6단계)
- 난이도 3단계(안정 85% / 도전 75% / 가속 65%) — 목표 정답률과 새 개념 슬롯 수가 함께 조정됩니다
- 학습자 프로필을 여러 개 만들 수 있고, 기록은 접속한 브라우저에 저장됩니다(기기 간 동기화는 미구현).

## 원리

이미 아는 맥락 80~90%에 새로운 맥락 10~20%를 섞어, 정답률 85% 부근을 계속 유지합니다.

1. 진단 12문항으로 개념별 현재 위치를 먼저 잡는다(0에서 시작하지 않음)
2. 매 문항마다 예상 정답률을 계산해 85%에 가장 가까운 난이도를 고른다
3. 세션 15문항 = 익숙 12 + 도전 3(새 개념은 세션당 3개씩 소진)
4. 오답 즉시 재교수 카드, 세션 끝에 '자기 전 5분' 복습 카드

배경 근거: 이해 가능한 입력(i+1, Krashen 1985), 최적 오류율 85% 규칙(Wilson et al., Nature Communications 2019), 수면 중 기억 공고화.

## 사용

`index.html`을 열면 바로 시작됩니다. AI에게 새 문항을 받아 붙여넣는 확장 루프는 앱의 [리포트] 탭에 있습니다.

## 빌드

이 저장소의 `index.html`은 생성물입니다. 콘텐츠·엔진 수정은 원본 생성기(`_build_app.py` + `_content_u1.py` / `_content_u2.py`)에서 하고, 아래 한 줄로 다시 만듭니다.

```
python _build_app.py --out <이 저장소>/index.html
```

원본 생성기는 개인 작업 폴더에 있으며 이 저장소에는 산출물만 둡니다.
